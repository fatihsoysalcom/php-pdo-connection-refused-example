# PHP PDO Connection Refused Example

This example demonstrates how to simulate and catch a PDO database connection refusal error in PHP, similar to the SQLSTATE[HY000] [2002] error discussed in the article. It attempts to connect to a non-existent database port, triggering a connection failure. The script then catches the `PDOException` and explains the common causes of this specific error.

## Language

`php`

## How to Run

Save the code as `app.php`. Run from your terminal using `php app.php`. Ensure PHP is installed on your system.
